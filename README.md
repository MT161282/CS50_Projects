# Harvard CS50x: Computer Science & Software Engineering Portfolio

This repository contains my solutions to the problem sets and the final capstone project completed as part of **CS50x: Introduction to Computer Science** offered by **Harvard University**[cite: 1].

The coursework covers low-level systems programming, data structures, algorithm optimization, database management, and full-stack web development[cite: 1].

---

## 🏆 Final Capstone Project: Smart_Calculator_Pro_Plus

* **Directory:** [`/Smart_Calculator_Pro_Plus`](./Smart_Calculator_Pro_Plus)
* **Description:** An advanced calculation and mathematical analysis application built with interactive user interface styling, modular architecture, robust input handling, and expression parsing[cite: 1].
* **Tech Stack:** HTML5, CSS3, JavaScript / Python backend logic.

## 📂 Repository Structure & Problem Sets

The problem sets are organized by academic weeks representing progressive complexity:

| Week | Focus / Domain | Key Topics & Implemented Solutions | Technologies |
| :--- | :--- | :--- | :--- |
| **Week 1** | C Fundamentals | Computational logic, loops, greedy algorithms (`cash.c`, `mario`) | C |
| **Week 2** | Arrays & Cryptography | String manipulation, command-line arguments, algorithmic ciphers (`readability`, `caesar`, `substitution`) | C |
| **Week 3** | Algorithmic Complexity | Searching, sorting algorithms, and voting models (`runoff`, `tideman`) | C |
| **Week 4** | Memory Management | Pointers, heap/stack allocation, BMP image filtering (`filter-less`, `recover`) | C |
| **Week 5** | Data Structures | Custom hash tables, linked lists, binary trees, dynamic memory (`speller`) | C, Makefile |
| **Week 6** | Python Scripting | Porting algorithmic tasks to Python, file automation, pattern analysis (`readability.py`, `dna.py`) | Python |
| **Week 7** | SQL & Databases | Relational schema design, nested queries, forensic database analysis (`fiftyville.db`) | SQL, SQLite |
| **Week 8** | Front-End Engineering | Responsive web design, event handling, DOM manipulation (`homepage`) | HTML5, CSS3, JS |
| **Week 9** | Full-Stack Web Development | MVC pattern, financial transaction workflows, API integration, session management (`finance`) | Python (Flask), SQLite, HTML/CSS |
